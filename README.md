# 🎓 Student Mental Health Analysis Dashboard

📌 Project Overview

The Student Mental Health Analysis Dashboard is an end-to-end data analytics project developed using Power BI, MySQL, and Excel to analyze and visualize factors affecting students' mental health.

This project focuses on identifying patterns related to stress, anxiety, academic performance, lifestyle habits, and student demographics through interactive dashboards and meaningful visual insights.

The goal of this project is to demonstrate how data analytics and business intelligence tools can support better understanding and decision-making in educational and mental health domains.

🛠️ Tools & Technologies Used
-    Power BI – Data visualization and dashboard creation
-    MySQL – Data storage and SQL querying
-    Microsoft Excel – Data cleaning and preprocessing
-    DAX (Data Analysis Expressions) – KPI calculations and measures

# 📊 Dashboard Features

This Power BI project contains 6 interactive dashboard pages:

1️⃣ Overview Dashboard
   - High-level summary of student mental health data
   - Key KPIs and metrics
   - Total students analyzed
   - Average stress and anxiety levels

2️⃣ Stress Analysis Dashboard
  -  Stress distribution analysis
  -  Stress comparison across departments
  -  Gender-wise stress insights
  -  Stress category segmentation

3️⃣ Anxiety Analysis Dashboard
 -   Anxiety level analysis
 -   Student anxiety trends
 -  Department and gender comparisons
 -   Anxiety severity visualization

4️⃣ Academic Performance Insights
  -  CGPA analysis
  -  Relationship between academic pressure and performance
  -  Performance comparison across student groups

5️⃣ Lifestyle vs Mental Health Dashboard
  -  Impact of sleep, study hours, and lifestyle habits
  -  Correlation between lifestyle factors and stress/anxiety
  -  Interactive filtering and drill-through analysis

6️⃣ Student Distribution & Summary Dashboard
 -   Overall student category distribution
 -   Summary insights and comparisons
 -   Visual storytelling dashboard

## 📈 Key Insights

Some important insights generated from the dashboard include:

-  Students with higher academic pressure tend to show increased stress levels
-  Lifestyle habits such as sleep and study balance impact mental health significantly
-  Certain departments reported comparatively higher anxiety levels
-  Mental health indicators vary across gender and academic performance groups
-  CGPA and stress levels show observable correlations in some student categories
